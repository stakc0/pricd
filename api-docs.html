Authentication

Browser clients authenticate with the wallet session cookie.

Errors follow one shape: { "error": { "code", "message", "details?" } }. Policy denials use HTTP 402 and include the policy decision.

Base URL: https://higgspad.com/api

curl
curl https://higgspad.com/api/tokens/LUNA/fees
POST/tokens

Create a token draft and its influencer archetype.

AuthSession cookie (creator) or API key
Parameters
  • namestring
    Display name, 2–32 chars
  • symbolstring
    Ticker, 2–8 uppercase chars
  • archetypestring
    One of the ARCHETYPES ids
Request body
{
  "name": "Luna AI",
  "symbol": "LUNA",
  "archetype": "fashion",
  "network": "devnet"
}
Response · 200
{
  "id": "tok_luna",
  "status": "draft",
  "symbol": "LUNA",
  "influencerId": null,
  "treasuryId": null,
  "createdAt": "2026-10-03T14:20:00Z"
}

POST/launch/prepare

Non-custodial launch, step 1: build the pump.fun create transaction for YOUR wallet (first buy included). The server only partially signs with a fresh mint key it never stores.

AuthSession cookie (creator), paid launch quote

Reserves the symbol for your wallet for 15 minutes. Sign and send the transaction with your wallet, then call /launch/confirm.

Request body
{
  "paymentQuoteId": "pq_…",
  "token": { "name": "Luna", "symbol": "LUNA", "category": "Fashion" },
  "launchConfig": { "launchpad": "pumpfun", "devBuySol": 0.5 },
  "feeSplit": { "treasuryPct": 35 },
  "influencer": { "name": "Luna", "username": "luna", "niche": "Fashion" },
  "characterJobId": "cgen_…"
}
Response · 200
{
  "intentId": "lnch_…",
  "mint": "7Gq…pump",
  "transaction": "<base64 VersionedTransaction, partially signed>",
  "mock": false
}
POST/launch/confirm

Step 2: confirm your create transaction on-chain. The token is recorded as pending_fee_setup.

AuthSession cookie (creator)

Returns 202 {status:"pending"} until the transaction confirms; keep polling (it is idempotent) and never prepare again for a sent transaction. Then POST /tokens/:id/fee-sharing (unsigned fee-sharing tx to sign) and /tokens/:id/fee-sharing/verify; the AI goes live once verified.

Request body
{ "intentId": "lnch_…", "signature": "3xk…Qm9" }
Response · 200
{
  "status": "confirmed",
  "tokenStatus": "pending_fee_setup",
  "tokenId": "tok_…",
  "symbol": "LUNA",
  "feeSharing": { "status": "pending", "expected": [{ "address": "Burn…", "bps": 3000, "role": "burn" }] }
}
GET/launch/pending

Your unfinished launches: tokens waiting for fee sharing and create transactions sent but not confirmed yet.

AuthSession cookie (creator)

Resume these instead of paying again: confirm each sent intent, then set fee sharing. /launch/prepare with an already used launch payment answers 409 already_launched with the token.

Response · 200
{
  "tokens": [{ "tokenId": "tok_…", "symbol": "LUNA", "name": "Luna", "mintAddress": "…pump", "feeSharing": { "status": "pending" } }],
  "sent": [{ "intentId": "lnch_…", "signature": "3xk…Qm9", "mint": "…pump", "symbol": "NOVA" }]
}

POST/influencers/:id/generate

Queue a video or image generation. Checked against the spending policy first.

AuthSession cookie (creator) or API key
Parameters
  • kind"video" | "image"
    Output type
  • scriptstring?
    Optional; the agent writes one if omitted
  • durationSecnumber
    4–20 for video
  • aspectRatio"9:16" | "1:1" | "16:9"
    Output aspect
  • styleVisualStyle
    Affects price multiplier

Returns 402 with { "policy": { "decision": "denied", "reason": "daily_limit" } } when the spend is not allowed, and 202 with decision "pending" when creator approval is required.

Request body
{
  "kind": "video",
  "script": "Three ways to wear one coat this week.",
  "scene": "Golden hour walk",
  "camera": "Slow push",
  "style": "Cinematic",
  "durationSec": 8,
  "aspectRatio": "9:16"
}
Response · 200
{
  "jobId": "gen_8a1f2c3d",
  "status": "queued",
  "estimatedCostUsd": 12.00,
  "policy": { "decision": "approved", "remainingTodayUsd": 25.00 },
  "provider": "higgsfield",
  "mock": true
}

PATCH/tokens/:id/fees

Locked: the fee split chosen at launch is final. Always answers 409.

AuthSession cookie (creator)

Choose the split in the launch flow (feeSplit.treasuryPct on /launch/prepare). It cannot be changed after creation.

Request body
{ "treasuryPct": 50 }
Response · 200
{ "error": { "code": "conflict", "message": "The fee split is locked at launch", "details": { "locked": true, "split": { "burnPct": 30, "treasuryPct": 35, "creatorPct": 35 } } } }
